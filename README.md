# ToDo List App
- A simple and responsive ToDo List Application built using HTML, CSS, and JavaScript.
- This project allows users to add and manage daily tasks with a clean and user-friendly interface.

# Features
- Add new tasks
- Delete tasks
- Responsive and clean UI
- Fast and lightweight

# Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)
